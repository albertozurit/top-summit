# Fuentes de datos y licencias

El código del repositorio está bajo MIT ([`LICENSE`](../LICENSE)). Este documento cubre los datos y los recursos de terceros. Esas licencias no se sustituyen por la MIT.

Criterio: solo datos cuya licencia permite **descarga masiva y uso offline**. No se descargan teselas de servidores de terceros (ni `tile.openstreetmap.org` ni proveedores gratuitos con prohibición de precarga): todas las teselas se generan en `pipeline/` a partir de datos brutos.

## Dónde se muestra la atribución

- Pie del mapa: atribuciones de las zonas instaladas (vienen en el `manifest.json`) + Natural Earth. Pulsar lleva a _Ajustes_.
- _Ajustes → Atribuciones y licencias_: lista completa + atribuciones de cada zona instalada.

## Descartado para M0–M2

- Servidores de teselas OSM, Thunderforest, MapTiler, Stadia, OpenFreeMap: su uso offline masivo contradice sus condiciones o no está claro.
- Meteorología (AEMET, Open-Meteo): aplazada a después de M2.
